## 📖 Documentation Format

Our documentation follows these conventions:
- **Guides**: Step-by-step instructions for specific tasks
- **References**: Comprehensive information about features and APIs
- **Tutorials**: Learning-oriented lessons with practical examples
- **Examples**: Real-world implementations you can study and use
