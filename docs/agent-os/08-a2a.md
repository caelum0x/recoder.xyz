# A2A

A2A is Recoder's agent/task transport. `TaskEnvelope` is the canonical cross-surface work unit for workspace, thread, trace, requester, assignee, connector, payload, result, error, policy, and history.

Every A2A ingress should validate envelopes, preserve trace IDs, emit canonical errors, and attach artifacts and audit events to shared run history.

## Bridge and orchestration contract

The Phase 2 bridge/admin API contract is implemented in `packages/a2a-sdk/src/bridge-contract.ts` and mirrored for interop tooling in `tools/a2a-interop/schemas/recoder-a2a-bridge-contract.schema.json`.

This contract covers bridge jobs, result submission, heartbeat and pairing sessions, policy documents, orchestration history, PM approval checkpoints, handoff checkpoints, runtime evidence, override requests, and recompute requests. It is the shared shape that lets PM, Agents, Agency, local bridges, and future runtimes attach state to one run history instead of creating surface-local copies.
