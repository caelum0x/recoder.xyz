# recoder-agency is FROZEN

Decision date: 2026-06-21 — see [`docs/direction.md`](../docs/direction.md).

## Status

`recoder-agency` (agency.recoder.xyz) is the **later monetization layer** (client
delivery: portal, deliverables, approvals, reports). Per `prd.md`, it *"should not
be the first product… first serious monetization layer once Spaces/tasks/artifacts/
approvals are solid."*

It is **frozen**, not removed:

- **Keep** the code and the existing deploy — do not delete.
- **Do not** invest in new agency features now.
- Engineering focus stays on the launch gate (`docs/remaining.md`) across the
  `app/` (consumer Spaces) and `recoder-agents/` (operator) surfaces only.
- Revisit once the core paid-user loop has real users and is solid.

Any change here beyond keep-it-building maintenance should reference an explicit
unfreeze decision.
