# 🚀 Getting Started - How to Run Recoder.xyz

## Prerequisites

Make sure you have these installed:
- **Node.js 18+** 
- **npm 9+**
- **Docker & Docker Compose**
- **Git**

## Quick Start (Automated Setup)

### 1. Clone and Setup
```bash
# Clone the repository
git clone <your-repo-url> recoder.xyz
cd recoder.xyz

# Run automated setup
chmod +x scripts/setup.sh
./scripts/setup.sh
```

The setup script will:
- ✅ Check system requirements
- ✅ Install all dependencies
- ✅ Build all packages
- ✅ Setup database with Docker
- ✅ Configure environment
- ✅ Link CLI globally

### 2. Configure API Keys
Edit `.env` file with your AI provider keys:
```bash
# AI Provider API Keys (Required)
ANTHROPIC_API_KEY=your_claude_api_key_here
OPENAI_API_KEY=your_openai_api_key_here
GOOGLE_API_KEY=your_gemini_api_key_here

# Optional - for local models
OLLAMA_BASE_URL=http://localhost:11434
```

### 3. Start All Services
```bash
# Start all services with Docker
docker-compose up -d

# Or start development servers locally
npm run dev
```

### 4. Test the CLI
```bash
# Test CLI installation
recoder --help

# Create your first project
recoder project create my-dex --type blockchain --network solana

# Generate real code
recoder generate "build a simple token swap interface"
```

## Manual Setup (Step by Step)

If you prefer manual setup or the script doesn't work:

### 1. Install Dependencies
```bash
# Install root dependencies
npm install

# Install workspace dependencies
npm run bootstrap
# or if bootstrap doesn't work:
cd packages/cli && npm install
cd ../shared && npm install
cd ../web && npm install
cd ../../backend && npm install
cd ../production-engine && npm install
```

### 2. Build All Packages
```bash
# Build everything
npm run build

# Or build individually
cd packages/cli && npm run build
cd ../shared && npm run build
cd ../../backend && npm run build
cd ../production-engine && npm run build
```

### 3. Setup Database
```bash
# Start database services
docker-compose up -d postgres redis

# Wait for services to be ready (30 seconds)
sleep 30

# Run database migrations
cd backend && npm run db:migrate

# Seed initial data
npm run db:seed
```

### 4. Link CLI Globally
```bash
cd packages/cli
npm link
```

### 5. Start Services Individually

**Backend Server:**
```bash
cd backend
npm run dev
# Runs on http://localhost:3001
```

**Production Engine:**
```bash
cd production-engine  
npm run dev
# Runs on http://localhost:3002
```

**Web Dashboard (Optional):**
```bash
cd packages/web
npm run dev
# Runs on http://localhost:3000
```

## Service URLs

When everything is running:
- **CLI**: Available globally as `recoder` command
- **Backend API**: http://localhost:3001
- **Production Engine**: http://localhost:3002
- **Web Dashboard**: http://localhost:3000
- **Database**: PostgreSQL on localhost:5432
- **Cache**: Redis on localhost:6379
- **Database Admin**: http://localhost:8080 (Adminer)

## Troubleshooting

### CLI Not Found
```bash
# Relink the CLI
cd packages/cli
npm run build
npm link
```

### Database Connection Issues
```bash
# Restart database services
docker-compose down
docker-compose up -d postgres redis

# Check database logs
docker-compose logs postgres
```

### API Key Issues
```bash
# Check environment variables
recoder config check

# Set API keys
recoder auth --provider anthropic --key your_key_here
```

### Build Issues
```bash
# Clean and rebuild
npm run clean
npm install
npm run build
```

### Port Conflicts
```bash
# Check what's running on ports
lsof -i :3001  # Backend
lsof -i :3002  # Production engine
lsof -i :3000  # Web dashboard

# Kill processes if needed
kill -9 <PID>
```
