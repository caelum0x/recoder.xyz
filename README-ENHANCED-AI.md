## 💻 Quick Start

### Installation

```bash
npm install @recoder/enhanced-ai
```

### Basic Usage

```typescript
import { AIOrchestrator } from '@recoder/enhanced-ai';

// Initialize with your API keys
const orchestrator = AIOrchestrator.getInstance({
  providers: {
    claude: { apiKey: process.env.ANTHROPIC_API_KEY },
    groq: { apiKey: process.env.GROQ_API_KEY },
    gemini: { apiKey: process.env.GOOGLE_API_KEY }
  },
  routing: {
    enableIntelligentRouting: true,
    fallbackEnabled: true
  }
});

// Generate production-ready code
const result = await orchestrator.generateCode({
  prompt: "Create a secure user authentication system",
  task: {
    type: 'code-generation',
    complexity: 'complex',
    language: 'typescript'
  },
  user: { id: 'user123', tier: 'pro' },
  options: { priority: 'quality' }
});

console.log(`Generated by: ${result.metadata.provider}`);
console.log(`Quality score: ${result.metadata.quality.score}`);
console.log(`Cost: $${result.usage.cost.toFixed(4)}`);
```

### Streaming Generation

```typescript
// Real-time code generation
const stream = orchestrator.generateCodeStream({
  prompt: "Build a complete e-commerce API",
  task: { type: 'code-generation', complexity: 'enterprise' },
  user: { id: 'user123', tier: 'enterprise' },
  options: { streaming: true, priority: 'balanced' }
});

for await (const chunk of stream) {
  if ('content' in chunk) {
    // Final result
    console.log('Generation complete!');
    return chunk;
  } else {
    // Stream chunk
    process.stdout.write(chunk.delta);
  }
}
```
