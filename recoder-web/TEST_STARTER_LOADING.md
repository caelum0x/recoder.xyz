## What You Should See

### Success Indicators:
1. ✅ **Fast responses** (<1 second for simple requests)
2. ✅ **"Loaded X starter with Y files"** message
3. ✅ **Artifact with all files** immediately visible
4. ✅ **No "generating..." messages** for base files
5. ✅ **Logs show "Direct return"** for simple cases

### What You Should NOT See:
- ❌ AI generating package.json
- ❌ AI generating app/layout.tsx
- ❌ AI generating component files one by one
- ❌ Long wait times for base project
- ❌ "Creating files..." messages for starter files

## Troubleshooting

### If starter isn't loading:
1. Check logs - is starter being detected?
   ```
   🎯 Search match: starter-name
   ```

2. Check if files are loading:
   ```
   📦 Preparing to inject starter
   ✅ Loaded: package.json
   ```

3. Check if /starters directory exists:
   ```bash
   ls -la /Users/arhansubasi/bolt.new/starters/
   ```

4. Try rebuilding:
   ```bash
   npm run build
   npm run dev
   ```

### If AI is still regenerating:
1. Check the query - does it include customization keywords?
   - "with", "add", "custom", "dark mode", etc.
2. Check logs for:
   ```
   → Direct return  ← Good! No AI
   → AI will customize ← AI adding features
   ```

### If starter isn't detected:
1. Try more specific query:
   - Instead of: "make something"
   - Try: "create a blog app"
2. Check search logs:
   ```
   🔍 Searching for: "your query"
   ⚠️  No starter template match found
   ```
3. Lower the minScore in starter-config.ts
