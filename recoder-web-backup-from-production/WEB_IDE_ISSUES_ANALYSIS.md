## 🎯 Executive Summary

After deep analysis of the recoder-web codebase, I've identified **4 critical issues** causing poor user experience:

1. ⚠️ **Conflicting Dev Server Logic** - Parser blocks `npm run dev`, but runner tries to handle it
2. 🐌 **Poor Progress Feedback** - Users don't know what's happening during long installs
3. 🤏 **Cramped IDE Layout** - Panels too small, preview hard to see
4. 👻 **Hidden Terminal Output** - AI executes commands but output is buried

## 📊 Issue Breakdown

### Issue #1: Conflicting Dev Server Logic (CRITICAL) 🔴

**Location:** `message-parser.ts` (Lines 22-53) vs `action-runner.ts` (Lines 167-287)

**The Problem:**
```typescript
// message-parser.ts BLOCKS dev server commands:
const forbiddenPatterns = [
  /npm\s+(run\s+)?dev\b/,
  /npm\s+start\b/,
  /yarn\s+dev\b/,
  // ... etc
];

// BUT action-runner.ts has sophisticated background execution:
const isDevServer = /npm (run )?dev|yarn dev|pnpm dev|vite|.../.test(normalizedContent);
if (isDevServer) {
  await this.#runDevServerInBackground(action);  // ✅ Works perfectly!
}
```

**Why It's Broken:**
- Parser **prevents** AI from generating dev server commands
- Runner has **perfect implementation** that would work if commands reached it
- Result: **AI never generates the commands** because parser rejects them
- Users **never see preview** without manual `npm run dev`

**Impact:** ⭐⭐⭐⭐⭐
**User Frustration:** Extremely High - "I generated a React app but can't see it!"

### Fix #1: Enable Dev Server Commands (Priority 1) ⚡

**File:** `recoder-web/app/lib/runtime/message-parser.ts`

**Action:** Remove dev server blocking, trust the runner's background execution

```typescript
// BEFORE (Lines 22-53):
export function validateShellCommand(command: string): {
  valid: boolean;
  error?: string
} {
  const forbiddenPatterns = [
    /npm\s+(run\s+)?dev\b/,  // ❌ BLOCKING
    /npm\s+start\b/,
    // ... etc
  ];

  for (const pattern of forbiddenPatterns) {
    if (pattern.test(command)) {
      return {
        valid: false,
        error: `Forbidden command detected: '${command}'. Dev server commands...`
      };
    }
  }

  return { valid: true };
}

// AFTER (SIMPLIFIED):
export function validateShellCommand(command: string): {
  valid: boolean;
  error?: string
} {
  // Only block truly dangerous commands
  const forbiddenPatterns = [
    /rm\s+-rf\s+\/\s*$/,     // rm -rf /
    /:\(\)\{\s*:\|:\&\s*\};:/,  // Fork bomb
    /mkfs\./,                 // Format disk
    /dd\s+if=/,               // Disk operations
  ];

  for (const pattern of forbiddenPatterns) {
    if (pattern.test(command)) {
      return {
        valid: false,
        error: `Dangerous command blocked: '${command}'`
      };
    }
  }

  // ✅ Allow npm run dev - action-runner handles it properly!
  return { valid: true };
}
```

**Expected Outcome:**
- AI generates: `npm install && npm run dev`
- Parser: ✅ Allows it
- Runner: ✅ Runs install, then dev server in background
- User: 🎉 Sees preview automatically!

**Time to Implement:** 15 minutes
**Impact:** ⭐⭐⭐⭐⭐
