## Quick Start

1. Open [ide.recoder.xyz](https://ide.recoder.xyz)
2. Add your AI API key (Settings → API Keys)
3. Type what you want to build
4. Watch AI generate your project

## Features

- 🤖 AI-powered code generation
- 📁 Full file system in browser
- 💻 Integrated terminal
- 👁️ Live preview
- 🔗 GitHub integration
- 📦 Download as ZIP
- 🔧 MCP tool support
