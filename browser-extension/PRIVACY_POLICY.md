# Privacy Policy - Recoder.xyz AI Code Assistant

**Last updated**: January 2025

## Overview

Recoder.xyz AI Code Assistant ("the Extension") respects your privacy and is committed to protecting your personal information. This Privacy Policy explains how we collect, use, and safeguard your data when you use our browser extension.

## Information We Collect

### Data We DO NOT Collect

- **Source Code**: Your code is never transmitted to our servers
- **Personal Files**: We don't access or store your local files
- **Browsing History**: We don't track your browsing activities
- **Personal Information**: We don't collect names, emails, or personal data
- **Usage Analytics**: We don't track how you use the extension

### Data We May Collect

**Extension Configuration**
- Local AI connection preferences
- GitHub API token (stored locally on your device)
- Extension settings and preferences

**Anonymous Telemetry** (Optional, can be disabled)
- Extension version and update status
- Error logs for debugging (no personal data included)
- Feature usage statistics (aggregated, anonymous)

## How We Use Your Data

### Local Processing First
- AI analysis is performed locally when possible
- Your code stays on your machine with local AI models
- No data transmission for local AI operations

### Cloud AI Fallback (Optional)
- When local AI is unavailable, you may choose to use cloud AI
- Only the specific code snippet you're analyzing is sent
- Transmitted via encrypted connections (HTTPS)
- Data is not stored on cloud AI provider servers

### GitHub Integration
- GitHub API calls are made directly from your browser to GitHub
- We act as a secure bridge between your browser and GitHub
- Your GitHub token is stored locally in your browser

## Data Storage

### Local Storage
- All settings are stored in your browser's local storage
- GitHub tokens are encrypted and stored locally
- No data is transmitted to external servers without your consent

### No Cloud Storage
- We don't maintain any cloud databases of user data
- Extension preferences are stored only on your device
- No user accounts or profiles are created

## Third-Party Services

### GitHub API
- Direct integration with GitHub's official API
- Subject to GitHub's Privacy Policy
- We don't store or log GitHub API responses

### AI Providers (Optional)
- When using cloud AI, data may be sent to:
  - OpenAI (GPT models)
  - Anthropic (Claude models)
  - Google (Gemini models)
- Each provider has their own privacy policies
- You can opt-out and use only local AI

### Local AI Models
- Ollama and LM Studio run entirely on your machine
- No data leaves your device
- Complete privacy and control

## Permissions Explained

The extension requests minimal permissions:

### Required Permissions
- **activeTab**: Access current tab only when extension is used
- **storage**: Store preferences locally in your browser
- **contextMenus**: Add right-click menu options

### Host Permissions
- **GitHub.com**: Provide AI assistance on GitHub pages
- **Recoder.xyz**: Connect to our web platform
- **Localhost**: Connect to local AI models on your machine

## Your Privacy Rights

### Data Control
- All data is stored locally on your device
- You can delete all extension data by removing the extension
- No data retention on our servers

### Opt-Out Options
- Disable cloud AI and use only local models
- Turn off anonymous telemetry
- Use extension completely offline

### Data Portability
- Export your settings anytime
- No vendor lock-in
- Open-source transparency

## Security Measures

### Technical Safeguards
- All communications use HTTPS encryption
- No sensitive data stored in plain text
- Secure token handling for GitHub integration
- Content Security Policy (CSP) protection

### Privacy by Design
- Minimal data collection
- Local processing preferred
- No tracking or analytics by default
- Transparent data handling
