# 03 — Studios

A Studio is a volume plus recoder-native-d. It is not an editor with MCP glued on.

States: cold → ready → built → playing → cooking → sleep.

Default engines: Bevy (desktop), Godot C# (mobile).
Unity / Unreal: cook workers behind the same 10 verbs.
