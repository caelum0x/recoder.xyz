# 🌐 DNS Setup Guide for Recoder.xyz Production Deployment

## Quick DNS Configuration

Once you have your production server running, configure these DNS records in your domain registrar:

### A Records (Point to your server's IP address)
```
Type    Name                Value
A       @                   YOUR_SERVER_IP
A       www                 YOUR_SERVER_IP
A       api                 YOUR_SERVER_IP  
A       engine              YOUR_SERVER_IP
A       app                 YOUR_SERVER_IP
A       chat                YOUR_SERVER_IP
A       traefik             YOUR_SERVER_IP
A       monitoring          YOUR_SERVER_IP
A       metrics             YOUR_SERVER_IP
```

### Example with IP 142.93.45.123
```
A       @                   142.93.45.123
A       www                 142.93.45.123
A       api                 142.93.45.123
A       engine              142.93.45.123
A       app                 142.93.45.123
A       chat                142.93.45.123
A       traefik             142.93.45.123
A       monitoring          142.93.45.123
A       metrics             142.93.45.123
```

## Common DNS Provider Instructions

### Cloudflare
1. Login to Cloudflare Dashboard
2. Select your `recoder.xyz` domain
3. Go to DNS > Records
4. Add the A records above
5. Set Proxy Status to "DNS Only" (grey cloud) for initial setup
6. After SSL works, you can enable "Proxied" (orange cloud)

### Namecheap
1. Login to Namecheap account
2. Go to Domain List > Manage
3. Click "Advanced DNS"
4. Add the A records above

### GoDaddy
1. Login to GoDaddy account
2. Go to My Products > DNS
3. Add the A records above

### Google Domains
1. Login to Google Domains
2. Select your domain
3. Go to DNS settings
4. Add the A records above

## Verification Commands

After configuring DNS, wait 5-15 minutes for propagation, then test:

```bash
# Test DNS resolution
nslookup recoder.xyz
nslookup api.recoder.xyz
nslookup app.recoder.xyz

# Test HTTP access (after deployment)
curl -I https://recoder.xyz
curl -I https://api.recoder.xyz/health
curl -I https://app.recoder.xyz
```

## SSL Certificate Notes

- SSL certificates will be automatically generated by Let's Encrypt via Traefik
- This happens after DNS is configured and services are running
- Initial certificate generation may take 1-5 minutes
- If SSL fails, check Docker logs: `docker-compose -f docker-compose.domains.yml logs traefik`

## Troubleshooting

### DNS Not Propagating
- Wait longer (up to 48 hours for full global propagation)
- Use online DNS checker tools
- Try different DNS servers: `nslookup recoder.xyz 8.8.8.8`

### SSL Certificate Issues
- Ensure DNS points to your server
- Check Traefik logs for Let's Encrypt errors
- Verify port 80 and 443 are accessible from internet

### Services Not Responding
- Check all Docker containers are running: `docker ps`
- Check service logs: `docker-compose -f docker-compose.domains.yml logs [service_name]`
- Verify firewall allows ports 80 and 443

## Production Server Requirements

- **Minimum**: 2 CPU cores, 4GB RAM, 50GB storage
- **Recommended**: 4 CPU cores, 8GB RAM, 100GB SSD storage
- **OS**: Ubuntu 20.04+ or similar Linux distribution
- **Ports**: 80 (HTTP), 443 (HTTPS) must be open to internet
- **Docker & Docker Compose** installed
