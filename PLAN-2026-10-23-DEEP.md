# Recoder — Deep Build Spec (2026-10-23)

Internal build doc. Terse. Four surfaces: `site/` (live), `app/` (built, not reachable — no DNS), `backend/` (built, not reachable — no DNS), `apps/desktop/` (shipped, arm64 .dmg live).

Symbol-only UI convention everywhere below: confirm = check glyph, submit/go = arrow glyph, close = x glyph, more = ellipsis glyph, settings = gear glyph. No emoji, no literal "Enter"/"Submit" button text.
