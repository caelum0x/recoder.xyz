## 🚀 Get Started Today

### Installation

#### CLI
```bash
npm install -g @recoder/cli
recoder config --setup-wizard
```

#### Web Platform
Visit [web.recoder.xyz](https://web.recoder.xyz) - no installation required

#### VS Code Extension
Search "Recoder" in VS Code Marketplace or:
```bash
code --install-extension recoderxyz.recoder-vscode
```

### First Steps
```bash
# Initialize your first project
recoder generate "full-stack blog with authentication"

# Try multi-AI routing
recoder generate "secure blockchain wallet" --auto-provider

# Test real deployment
recoder deploy --target vercel
```
