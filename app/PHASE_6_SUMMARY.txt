💼 BUSINESS LOGIC FLOWS
───────────────────────────────────────────────────────────────────────────────

UPGRADE FLOW
  1. User selects plan → /billing/upgrade
  2. Frontend requests proration → /api/billing/proration
  3. User confirms upgrade → /api/billing/upgrade
  4. Redirect to Paddle/DODO checkout
  5. User completes payment
  6. Provider webhook fires → /api/webhooks/[provider]
  7. Database updated (plan, status, dates)
  8. Audit log created
  9. User redirected to success page
  10. Access immediately upgraded

CANCELLATION FLOW
  1. User navigates → /billing/cancel
  2. Selects reason + provides feedback
  3. Chooses timing (immediate or end of period)
  4. Confirms cancellation (double check)
  5. API processes → /api/billing/subscription/cancel
  6. Provider API called (Paddle/DODO)
  7. Database updated (status, dates, reason)
  8. Audit log created
  9. User sees confirmation
  10. Access continues until effective date

ANALYTICS FLOW
  1. User opens dashboard → /dashboard
  2. Frontend requests data → /api/dashboard/overview
  3. Backend queries database (Prisma)
  4. Aggregates usage by day/model
  5. Calculates statistics
  6. Generates insights
  7. Returns formatted data
  8. Frontend renders charts
  9. User can export → /api/usage/export
  10. Downloads CSV/JSON
