```typescript
// Account
PUT  /api/user/account          - Update account settings
DELETE /api/user/account        - Delete account
GET  /api/user/export           - Export user data

// Profile
GET  /api/user/profile          - Get profile
PUT  /api/user/profile          - Update profile
POST /api/user/avatar           - Upload avatar
DELETE /api/user/avatar         - Remove avatar

// Security
POST /api/user/security/password     - Change password
POST /api/user/security/2fa          - Enable/disable 2FA
GET  /api/user/security/sessions     - List sessions
DELETE /api/user/security/sessions   - Revoke session

// Notifications
GET  /api/user/notifications    - Get notification settings
PUT  /api/user/notifications    - Update settings

// Integrations
GET  /api/integrations          - List integrations
POST /api/integrations/connect  - Connect integration
DELETE /api/integrations/disconnect - Disconnect

// API Config
GET  /api/user/api-config       - Get API configuration
PUT  /api/user/api-config       - Save configuration
POST /api/user/api-key/validate - Validate API key
```
