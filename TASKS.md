## Root causes (honest assessment):

1. **Too many moving parts**: 6 frontend apps + Python backend + Docker backend + nginx + Daytona + Cloudflare + PostgreSQL. Each connection point fails.
2. **Better Auth multi-subdomain**: Suna doesn't have this problem because single domain. We have 6 subdomains sharing cookies.
3. **Daytona exec layer**: Triple-encoding (command → base64 → sh -c → JSON → API) breaks long commands. Suna's Python SDK handles this better.
4. **No testing**: Every fix breaks something else. No E2E tests, no CI, no staging.
5. **Overcommitting**: Claimed hundreds of "FIXED" items that weren't actually tested in browser.
